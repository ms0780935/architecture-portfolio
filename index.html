三項實際改善歷程紀錄 (前後對照)

改善一：作品圖片管理與本機裝置抽換機制（落實資料管理功能 +10 分）

原問題：純靜態作品集若要抽換個人手繪與 CAD 圖，必須修改原始碼或重新 build，一般同學操作門檻極高。

改善決定：導入瀏覽器原生 IndexedDB 儲存引擎，設計拖曳上傳與檔案選擇器，將圖檔轉為二進位/DataURL持久化於本機裝置，並提供 JSON 備份匯出匯入功能。

驗證方式：從本機拖曳新圖上傳，重新整理頁面後，作品卡片與閱讀器依然成功保留個人圖紙，且可一鍵重設。

改善二：Divisare 風格之極簡編輯排版與分頁瀏覽體驗

原問題：傳統網頁作品集多使用花俏彈窗或單頁瀑布流，打斷建築系評圖注重「圖說閱讀連續性」之專業體驗。

改善決定：參考 Divisare 典範，改為純黑白高對比編輯風格、襯線字體與大尺度圖紙框；並加入鍵盤左右鍵（← / →）與頂部「01 / 10」無縫分頁切換。

驗證方式：在彈窗中直接按方向鍵可流暢切換作品，URL hash 隨之更新（支援深層連結），帶來雜誌翻頁般之沉浸感。

改善三：多國語系 (中/英 i18n) 與時間軸/課程向度交叉檢索

原問題：原有建築設計、選修與研究混雜，且建築系常需申請國外研究所或國際競圖，單一語言限制推廣性。

改善決定：建構完整雙語詞典與雙語作品資料庫（包含結構剖面、計算設計、空間句法專有名詞）；並設置一到五年級時間軸與課程分類雙向聯動篩選。

驗證方式：點擊右上角「ENGLISH / 繁體中文」按鈕，全站所有標題、專案論述、圖說與介面皆在 0.1 秒內無縫切換。
